# SillyTavern Keep Alive (Mobile)

繁體中文 | [English](README.md)

一個 SillyTavern 擴充功能，防止 Android Chrome 在切換應用程式時暫停 SillyTavern 的分頁，讓長時間的生成可以在背景順利完成。

## 問題

行動版 Chrome 會積極暫停背景分頁。當你按下「Send」之後切換到其他應用程式等待回覆時，Chrome 經常會中斷進行中的 LLM 請求，導致沒有回應或回應被截斷。

## 解決方法

Chrome 對於「正在播放可聞媒體」的分頁會豁免背景暫停。本擴充功能透過 `<audio>` 元素播放一連串幾乎聽不到的白噪音脈衝（每 5 秒一個約 40 毫秒的爆發、約 1.5% 音量），達到以下效果：

- Chrome 顯示分頁喇叭圖示
- Android 在通知欄顯示媒體工作階段
- 分頁不會被暫停
- 人耳與手機喇叭幾乎察覺不到

脈衝之間有極低（約 -66 dB）的白噪音背景，避免 Chrome 的音訊偵測器將串流視為靜音。純粹靜音是行不通的（Chrome 會視為沒有音訊）。

## 安裝

在 SillyTavern 內：

1. 開啟「擴充功能」面板（魔法棒 🪄 圖示）
2. 點擊「**Install extension**」
3. 貼上本儲存庫的 URL：
   ```
   https://github.com/TeaBay/SillyTavern-Keepalive
   ```
4. 安裝完成後，**在 SillyTavern 內點擊一次或傳送一則訊息**以啟動（瀏覽器的自動播放政策要求必須有使用者手勢才能播放音訊）
5. 確認 Chrome 分頁出現 喇叭圖示

## 驗證

1. 開始一個長時間的生成
2. 切換到其他應用程式
3. 等待預期時間
4. 返回 SillyTavern — 回應應該已經完成

如果分頁仍然被中止：請檢查切換應用程式之前喇叭圖示是否已經出現。若尚未出現，代表使用者手勢還沒有觸發音訊 — 請先在 SillyTavern 內再點擊一次。

## 設定（UI 版本）

開啟「擴充功能」面板（🪄）→ 捲動至「**Keep Alive (Mobile)**」抽屜，共 4 個輸入欄位：

| 設定 | 預設值 | 作用 |
|---|---|---|
| Pulse amplitude（脈衝振幅） | 0.015 | 每次爆發的音量。數值越低越安靜。 |
| Background floor（背景底噪） | 0.0005 | 脈衝之間的持續低噪。**請勿設為 0** — Chrome 會視為靜音而停止豁免分頁。 |
| Pulse duration（脈衝時長 / 秒） | 0.04 | 每次爆發的持續時間。 |
| Pulse interval（脈衝間隔 / 秒） | 5 | 兩次爆發之間的間隔。數值越大感覺越安靜。 |

點擊 **Apply** 即時以新設定重新建立音訊。設定會在重新載入後保留。

如果仍然聽得見：將脈衝振幅調低（嘗試 `0.005`），或將脈衝時長縮短（嘗試 `0.02`），或將脈衝間隔加長（嘗試 `10`）。

如果保持喚醒功能失效（分頁仍然被暫停）：將背景底噪提高至 `0.001` 或 `0.002` — Chrome 的靜音偵測器可能已將你的串流標記為靜音。

## 已知限制

- 僅在 Android Chrome 上測試過。iOS Safari 的音訊與背景策略不同，可能無法正常運作。
- 部分手機 ROM（小米 MIUI、華為 EMUI、OnePlus OxygenOS 的深度最佳化模式）會在作業系統層級終止 Chrome 程序，無論音訊狀態如何。請在系統電池設定中將 Chrome 加入白名單。
- 程式會請求 Wake Lock，但 Android 通常會在螢幕關閉時釋放。

## 安全性

- 沒有網路呼叫。
- 不下載任何外部資源。
- 音訊在瀏覽器執行階段內部產生 — 沒有打包任何音訊檔案。
- 不會接觸聊天記錄、設定或 API 金鑰。
- 可隨時在「擴充功能」面板中停用。
